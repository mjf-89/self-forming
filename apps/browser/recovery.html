Recovery

Use this page if the app doesn't start, looks broken or stops responding after a change. Nothing here deletes your conversations, files, sign-ins or saved versions.

This page and safe mode run only the app's fixed, deployed code — never an edited app version or an installed plugin — so they work even when those are broken.

The app is open in another tab. Close it there to make changes here (this page waits for it), or take over: that tab then stops.
