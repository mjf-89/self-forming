# 0.6.0 — native plugin lanes (candidate)

## Native (Kotlin)
- Kotlin -> page plugin events (`PluginContext.emit`, `PiPlugins` channel, web `ctx.native.on`).
- `plugins.read`: the page reads files of the selected/pinned plugin snapshot (skills as files).
- Plugin credentials: `auth.*` with `plugin:<id>:<name>`, encrypted per record (Android Keystore).
- User-managed endpoint allow-list for native HTTP (`http.allowList.get/set`).
- New `host.info` capabilities: nativePlugins, pluginEvents, pluginRead, pluginCredentials, httpAllowList.
- Plugin directory resolved behind Android's `/data/user/0` symlink (0.5.1 fix kept).

## Web (since 0.5.1, already live as revisions)
Agent tools, prompt sections, skills, servers, model providers and the page session lifecycle as plugins; Settings -> Plugins with bundles; missing providers keep their chats; servers stop/restart verified; editions (public/private); `apps/common`.

## Verification
JVM checks (Track B 10, foundation 15) and all `tests/plugin-*` pass (Node 18, per file). On-device: events, plugins.read, credentials and allow-list are to be checked after install.
