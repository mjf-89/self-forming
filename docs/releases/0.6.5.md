# 0.6.5 — pi-durable, pi-ai and chord 1.3.0 (candidate)

## Library
- `dist/app/library` is built from the published `@earendil-works/{pi-durable,pi-ai,chord}@1.3.0` (was 1.0.4) with
  `node scripts/build.mjs` (Node 24, pnpm 11; no Bun needed). A library change cannot ship as an `app_update` revision
  (`library/` is refused), hence this APK.
- Upstream fixes this release takes (pi-durable CHANGELOG 1.2.0/1.3.0): a generation whose blocking compaction failed now
  fails with `model_error` instead of sending a request that leaves no room for an answer (the empty `length` replies
  of a 996K-of-1M conversation); summaries leave thinking out; `pi.live.compactionFailure`; the post-compaction system
  baseline leads the context.

## App adaptations
- Tool results: `content` → `output` (1.2.0 Breaking Changes); legacy plugin results are passed on by the host
  compatibility wrap (`agent-extensions.js` `compatibleExtension`, docs/plugins.md).
- A storage error fails the Harness (`SessionFailed`); the page reopens the session (docs/durability.md).
- Retries: `settings.retry` 1000 retries, upstream backoff capped at 60 s; one "Retrying (n) in Ns…" status line.

## Rollback
`self-forming-0.6.4-25-rollback.apk` (instance-0.5.1 tree built as 0.6.4, versionCode 25, library 1.0.4) installs over
0.6.5 (code 24). Conversations stored by 1.3.0 (pi.tool v2 tasks, task `startedAt`/`endedAt`) are not guaranteed to
read back under 1.0.4: roll back only if 0.6.5 does not start.
