# Self Forming 0.4.2

This release installs as **Self Forming** (`md.incept.selfforming`). Later releases retain the same permanent signing identity.

- Native pi-durable context sections tailored to each subagent's available tools.
- Durable subagent replay, result delivery and cancellation; missing model credentials preserve pending work.
- Managed servers recover through the scheduler and verify cleanup after Stop.
- Context compaction enabled.
- Clean source included for on-device rebuilding, with no Git history.
- Sign-in returns directly to Self Forming through its `selfforming` app link.
- Subagent reports identify the sending agent in the conversation.
- App updates activate after their tool result is saved, without waiting for unrelated subagents or the currently viewed child to become idle. Reload waits for the saved session to close before activating the new revision; interrupted work resumes afterward.

CI reuses checksum-pinned ARM64 Ubuntu, Box64 and PRoot assets. Fast JavaScript checks, Android JVM tests and APK verification run before publication. No emulator or physical-device run is implied; see the included verification report.

The signing key and password are deliberately included inside the APK so the app can rebuild and update itself. Anyone with the APK can extract that key and sign a compatible update. Git source archives exclude the key; Actions receives the permanent identity through repository secrets.
