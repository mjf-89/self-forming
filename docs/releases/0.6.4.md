# 0.6.4 — cors-rot served from the APK; Tor and Tailscale providers (candidate)

## Fixed assets
- `libs/cors-rot` is packaged as `assets/web/cors-rot/` (tests/ and demo/ left out; incl. `vendor/tailscale/tailscale.wasm`,
  ~37 MB, and `vendor/webtor/*`) and every file is listed in `immutableFiles` of `app-manifest.json`, like `fonts/`.
- `WebAppStore` therefore serves them from the APK while an `app_update` revision is active (a revision cannot carry them:
  4 MiB per file) and refuses a revision that tries to override them. Covered by a new JVM unit test
  (`corsRotFilesAreFixedApkAssetsServedWhileARevisionIsActive`). `.wasm` is served as `application/wasm`.
- No Kotlin change was needed in `WebAppStore`.
- Build note: the two big `.wasm` files are git-excluded; copy them from `libs/cors-rot` and check them against
  `libs/cors-rot/UPSTREAM.lock` before building from a clean worktree.
