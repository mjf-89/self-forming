# 0.6.1 — built-in plugins own their Kotlin half (L2, candidate)

## Native (Kotlin)
- Pure moves, no behaviour change: the Kotlin of core-execution, core-plugin-management, core-providers-chatgpt and core-self-update now lives in `plugins/<id>/native/src` with optional `native/manifest.xml` fragments; Gradle compiles it statically and merges the fragments (docs/plugins-providers-agent-core.md §J).
- Web revisions need only the minimal host files (index.html, app.js, app.css, plugin-bootstrap.js, plugin-runtime.js, builtin-plugins.js); other files may move or disappear between revisions.
- The host keeps MainActivity, NativeBridge routing, recovery, shared auth/secret/store classes and the plugin SDK.

## Rollback
`self-forming-0.6.0-15-rollback.apk` (0.6.0 code 15, tree 5c9e379) installs over 0.6.1 (code 14) without uninstalling.
