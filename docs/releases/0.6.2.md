# 0.6.2 — native route registry for built-in Kotlin halves (R1, candidate)

## Native (Kotlin)
- Built-in Kotlin halves register themselves: each `plugins/<id>/native/src` declares `internal object <PascalCaseId>Native : BuiltinNative` (`apps/android/.../BuiltinNative.kt`); Gradle generates `BuiltinNatives.ALL` from the plugin folders present. NativeBridge, MainActivity, SettingsActivity and NativeAuth no longer name plugin classes, so a fork can drop a folder without host edits.
- core-execution: `env.*` routes (+ executionEnv/shell/backgroundExecution flags); core-plugin-management: `plugins.*`, the PiPlugins event channel, `/assets/web/plugins/` assets, "Disable all plugins" recovery (+ plugins/nativePlugins/pluginEvents/pluginRead); core-self-update: `apk.install` (+ apkInstall); core-providers-chatgpt: the loopback browser sign-in behind `auth.listen/open/wait/cancel`.
- No change for the web layer: same bridge method names, JSON shapes and `host.info` capabilities.

## Rollback
`self-forming-0.6.1-17-rollback.apk` (0.6.1 code 17, tree fd2049e) installs over 0.6.2 (code 16) without uninstalling.
