# 0.7.0 — first public release (experimental)

Self Forming is an app you shape by talking to it. It is an experiment: expect rough edges.

## What's in it
- **Android app** (APK below) and the **browser edition** at https://demo.selfforming.incept.md.
- **Everything is a plugin:** chat, conversations, storage, execution, network, sign-in, secrets, subagents, servers,
  tools, prompt and skills are built-in plugins with their own code; new features are added as plugins.
- **Models:** ChatGPT and Claude sign-in, OpenAI API key, offline demo; durable conversations (pi-durable 1.3.0) that
  survive restarts, with automatic compaction and retries.
- **Network providers** (Settings → Providers): native, page fetch, Tor (Snowflake) and Tailscale (via cors-rot).
- **Browser edition:** in-browser Linux (v86 + Alpine), JavaScript environment, git (through the selected network).
- **Subagents** listed under their conversation; archive/unarchive (also forks), active ones cannot be archived.
- **App updates** reload at once; the conversation that applied the update continues by itself afterwards.
- Release build (not debuggable), ">_" icon, loading screen in the browser edition.

## Read before installing
- **The APK contains its own signing key** (so the app can rebuild itself): install Self Forming only from this release
  page and check the SHA-256 against `SHA256SUMS`. See the README, "About the signing key".
- Needs a ChatGPT or Claude account, or an OpenAI API key. The first self-rebuild downloads Android build tools
  (several GB).
- Licences of bundled third-party code: `THIRD_PARTY.md`; GPL source offer for the browser Linux image:
  `docs/gpl-source-offer.md`.

## Known limitations
- Tor on Android may hang after connecting (works in the browser edition).
- Renaming a conversation does not work yet.
- Browser sign-in needs pasting the callback URL and a Tor/Tailscale route for some providers.
